---
name: Mockup Sandbox Generated File
description: The mockup-sandbox imports a file that only exists at runtime, causing clean-checkout typecheck failures
---

## Rule
`artifacts/mockup-sandbox/src/.generated/mockup-components.ts` is auto-generated by `mockupPreviewPlugin.ts` when the Vite dev server starts. It does **not** exist in the repo.

`App.tsx` imports it directly — so `tsc --noEmit` on a clean checkout will fail with "cannot find module" unless the dev server has run at least once to generate the file.

**Why:** Discovered during full project audit. Prevents confusion when typecheck fails in CI or fresh environments.

**How to apply:** If typecheck fails on mockup-sandbox with a missing module error, start the dev workflow first (`artifacts/mockup-sandbox: Component Preview Server`) then re-run typecheck.
